# AgroFlow Enterprise Approval Management System

AgroFlow is a centralized Enterprise Approval Management System.

## Phase 1 Modules

1. IOU Management
2. Petty Cash Management
3. Procurement Process Management

## Technology Stack

### Frontend
- Angular
- TypeScript
- Angular Material
- HTML5
- SCSS

### Backend
- Java
- Spring Boot
- Spring Security
- JWT
- REST API
- JPA / Hibernate

### Database
- PostgreSQL

## Project Architecture

The system will use a reusable approval workflow engine that can support multiple enterprise approval processes.
